# 🖥️ 自作PC（Windows）完全乗り換え ＆「共通の脳・麦わらの一味7人」引き継ぎガイド

このフォルダ（`00_自作PC完全移行パック_2026-11`）には、MacBook Air 上で稼働している **すべてのシステム・暗号化データベース・画像/動画スタジオ・旅行マスター・麦わらの一味7人（Antigravity & Claude）の記憶とスキル** が丸ごとパッケージングされています。

---

## 🚀 自作PC側でやること（たった3ステップ・約5分）

### ステップ1：必須ソフト4つをインストール（未導入の場合のみ）
自作PC（Windows）の PowerShell（またはターミナル）を開き、以下のコマンドを貼り付けて Enter を押すと一括で入ります（すでに入っているものはスキップされます）：

```powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.11 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Obsidian.Obsidian -e
```
（※これに加えて、普段お使いの **Google Drive for Desktop**、**Antigravity**、**Claude Desktop / Claude Code** をインストールしてログインしてください）

---

### ステップ2：GitHub にログイン（初回1回だけ）
最初にリポジトリをクローンするとき、ブラウザで GitHub のログイン画面が開いたら `promisefree-cmyk` アカウントで承認してください。

---

### ステップ3：このフォルダのワンクリックスクリプトを実行！

#### 【A】Windows ネイティブで使う場合（おすすめ・一番簡単）
このフォルダにある **`01_自作PC一括セットアップ_Windows.bat`** をダブルクリックしてください。
（または PowerShell で `01_自作PC一括セットアップ_Windows.ps1` を実行）

#### 【B】Windows の WSL2（Ubuntu）または新Macで使う場合
ターミナルでこのフォルダに移動し、以下を実行してください：
```bash
bash 02_自作PC一括セットアップ_WSL_Mac.sh
```

## 🔄 普段の同期方法（Mac ⇄ 自作PC）

1. **「共通の脳（Obsidian）」の同期**
   - 作業前後に `~/Obsidian/Claude(年収5億)` で `git pull` / `git push` するだけ（または `.setup/obsidian_win.ps1` を実行）。
   - Antigravity も Claude も、起動時に必ず `共通の脳/はじめに読む.md` と `共通の脳/直前の引き継ぎ.md` を読むため、**Macで話していた続きを1秒後には自作PCのAIが100%理解した状態で再開**できます。
2. **マスタースタジオ（Port 8765）の起動**
   ```powershell
   cd ~\douga
   python studio_server.py
   ```
   ブラウザで `http://127.0.0.1:8765/blog-studio.html` を開くと、Macと全く同じマスタースタジオが動きます（Windows標準の游ゴシック・メイリオ・BIZ UDPゴシック・游明朝へ自動フォールバックするため文字化けゼロです）。
3. **予約・問診・電子カルテシステム（Port 3456）の起動**
   ```powershell
   cd ~\Documents\antigravity\wise-darwin
   node server.js
   ```
   暗号化キー（`data/.master_key`）とSQLiteデータベースがそのまま引き継がれているため、既存の患者様カルテ・予約データもすべてそのまま復号・閲覧できます。
