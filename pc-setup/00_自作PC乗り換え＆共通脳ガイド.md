# 🖥️ 自作PC（Windows）完全乗り換え ＆「共通の脳・麦わらの一味7人」引き継ぎガイド

このガイドでは、MacBook 上で稼働している **公式HP・共通の脳・画像/動画スタジオ・予約システム・麦わらの一味7人（Antigravity & Claude）の記憶とスキル** を自作PC（Windows）と100%同じ状態に保つ手順をまとめています。

---

## 🛡️ すでに移行済みの自作PCを最新状態にする方法（約3秒・一番簡単！）

1. Webポータル（`https://promisefree-cmyk.github.io/trip/pc-setup/`）から **`update_win_security.bat`** をダウンロードしてダブルクリックします。
2. 全自動で以下が完了します：
   - GitHubから最新の「共通の脳（`.ai-brain`）」と「公式HP（`rooton-claude` 全78ページ・`v3.3.94` Fortress v9）」を取得
   - 麦わらの一味7人クルー・検閲ルール（`judge_rules.json`）を最新同期
   - Windowsのファイル保護機能（`icacls`）で設定ファイルや認証ファイルをご本人のアカウント専用にロック

## 🚀 初回セットアップ（まだ移行していない場合・たった3ステップ）

### ステップ1：必須ソフト4つをインストール（未導入の場合のみ）
自作PC（Windows）の PowerShell（またはターミナル）を開き、以下のコマンドを貼り付けて Enter を押すと一括で入ります：

```powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.11 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Obsidian.Obsidian -e
```
（※これに加えて、普段お使いの **Antigravity**、**Claude Desktop / Claude Code** をインストールしてログインしてください）

### ステップ2：GitHub にログイン（初回1回だけ）
最初にリポジトリを取得するとき、ブラウザで GitHub のログイン画面が開いたら `promisefree-cmyk` アカウントで承認してください。

### ステップ3：ワンクリックインストーラーを実行！
移行パックフォルダ内の **`01_自作PC一括セットアップ_Windows.bat`**（または `setup_win.bat`）をダブルクリックすると、全パッケージの配置とデスクトップショートカット作成まで自動で完了します。
